## Engineering Principles

> *"Great software isn't built by writing more code. It's built by writing the right code."*

- **Performance:** fast first load and quick interactions.
- **User experience:** interfaces that are clear and pleasant to use.
- **Security:** authentication and access control designed in from the start.
- **Scalability:** structure that still works when the project grows.
- **Continuous improvement:** debugging teaches me more than writing code does, so I treat every bug as a lesson.

AI is my productivity partner, not a replacement for engineering.
