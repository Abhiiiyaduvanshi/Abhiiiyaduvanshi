# Font license notes

- **Inter Display Bold**: Inter Project Authors. Redistributed under the SIL Open Font License 1.1; see `Inter-Font-License.txt` copied from the system's Inter font package copyright notice.
- **Go Mono**: Source file `/usr/share/fonts/fonts-go/Go-Mono.ttf`; the font belongs to the Go font set. Its license should be checked in the relevant Go source distribution before redistributing outside this package. The WOFF2 data is embedded in the SVG files.

If distributing the profile package publicly, verify the Go Mono font license text for the exact installed package version.
